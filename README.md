# ReRun (New Game Templates)

Fast preset manager for saving and loading new game setups in **S.T.A.L.K.E.R. Anomaly / G.A.M.M.A.** without overwriting interface files.

## English

### Overview

**ReRun** is a quality-of-life add-on for S.T.A.L.K.E.R. Anomaly and G.A.M.M.A. that allows you to instantly save and restore complete new game configurations.

Saves your chosen faction, character name, icon/portrait, spawn location, difficulty, economy presets, starting gear (loadout), and all gameplay modes (Story, Mystery of the Zone, Warfare, Survival, Ironman, Campfires, Routes, Timer, Soulslike, etc.).

### Key Features

- **Zero UI Overwrites (100% Conflict-Free):** The mod does not overwrite , , or . The button and manager dialog are injected non-destructively via DXML and script hooks, making it completely immune to UI mod conflicts and modpack updates.
- **Modern & Legible UI:** Redesigned dialog window featuring high-contrast text fields, enlarged crisp font (), and intuitive status cues.
- **Interactive FOMOD Installer:** Choose from 6 button positions on the character creation screen (, , , , , ) to fit any custom UI layout.
- **Up to 24 Preset Slots:** All templates are saved to  (under ), ensuring your presets persist across mod updates and reinstalls.

### Installation

1. Download the latest  from [Releases](https://github.com/curesadrain/ReRun/releases).
2. Install via **Mod Organizer 2** (*Install a new mod from an archive*).
3. Select your preferred button placement in the FOMOD installer and click **Install**.
4. Enable the mod in your load order. Load order relative to UI mods does not matter.

> **Upgrading from v1.0.x:** Select **Replace** when installing in MO2 to ensure legacy overwritten  files are cleanly removed.
